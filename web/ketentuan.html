01. Syarat & Ketentuan Lisensi Software

Berlaku mengikat sejak aktivasi serial key resmi BukuKasir UMKM dilakukan.

1. Sifat Kepemilikan Sekali Bayar Seumur Hidup (Lifetime)

BukuKasir UMKM diterbitkan dengan skema lisensi sekali bayar seumur hidup (Lifetime License). Pembeli tidak akan dikenakan biaya sewa bulanan, biaya langganan tahunan, biaya pemeliharaan berulang, atau biaya transaksi kasir dalam bentuk apa pun.

2. Kapasitas & Penggunaan Perangkat

Satu (1) Serial Key Lisensi resmi didaftarkan untuk nama toko Anda dan berlaku permanen pada satu (1) unit komputer atau laptop operasional kasir. Untuk kebutuhan cabang toko baru yang independen, diperlukan serial key tambahan terpisah.

Jaminan Ganti Perangkat & Instal Ulang: Apabila komputer toko Anda mengalami kerusakan perangkat keras, diformat ulang, atau Anda memutuskan untuk mengganti ke laptop kasir baru, lisensi resmi Anda tetap berlaku dan dapat diaktifkan kembali tanpa biaya tambahan menggunakan nomor serial key resmi serta berkas cadangan (backup) database toko Anda.

3. Hak Pembaruan Software (Update)

Setiap pemegang lisensi resmi berhak mengunduh dan memasang berkas pembaruan stabil (bugfix dan peningkatan performa) yang dirilis secara berkala melalui repositori rilis resmi tanpa dipungut biaya tambahan.

4. Pembatasan dan Hak Cipta

Seluruh kode sumber, arsitektur, dan hak kekayaan intelektual BukuKasir UMKM dilindungi oleh undang-undang. Pengguna dilarang keras menjual kembali lisensi bajakan, mendistribusikan ulang serial key secara ilegal, atau melakukan rekayasa balik (*reverse engineering*) terhadap modul otentikasi lisensi resmi.

02. Kebijakan Privasi & Kedaulatan Data Toko

Komitmen integritas perlindungan data privasi pemilik usaha UMKM.

1. 100% Kedaulatan Data Lokal (Offline-First)

BukuKasir UMKM dibangun dengan prinsip *zero-cloud dependency*. Seluruh data inventaris barang, harga modal, harga jual, rincian transaksi belanja, laporan laba rugi, serta riwayat pembayaran Uang Muka (DP) disimpan secara lokal di perangkat toko Anda disertai fitur ekspor/impor cadangan JSON mandiri. Data Anda tidak pernah diunggah ke server cloud publik.

2. Nol Pelacakan Bisnis & Bebas Penyadapan Omzet

Kami tidak memantau, tidak mengumpulkan, dan tidak memiliki akses teknis apa pun terhadap angka penjualan harian, omzet toko, maupun data konsumen toko Anda. Rahasia dagang dan margin keuntungan usaha Anda sepenuhnya berada di bawah kendali mandiri Anda sendiri.

Penggunaan Data Saat Pembelian Lisensi: Informasi yang Anda cantumkan pada saat pemesanan lisensi (Nama Toko, Nama Pemilik, dan Alamat Email) semata-mata digunakan untuk memverifikasi pembayaran gateway QRIS Pakasir dan menerbitkan sertifikat serial key resmi toko Anda. Kami tidak pernah membagikan atau menjual data kontak Anda kepada pihak ketiga.

3. Keamanan Transaksi QRIS

Proses pembayaran transaksi lisensi diproses secara otomatis melalui payment gateway resmi Pakasir yang terintegrasi dengan jaringan National QRIS Bank Indonesia. Kami tidak menyimpan informasi perbankan, PIN, maupun data finansial sensitif Anda.

4. Cadangan Mandiri (Backup Mandiri)

Mengingat data tersimpan secara lokal pada komputer toko, pemilik usaha sangat disarankan untuk melakukan ekspor cadangan database secara berkala (misalnya ke flashdisk atau Google Drive pribadi) melalui menu backup yang tersedia di aplikasi demi mengantisipasi kehilangan data akibat kerusakan fisik perangkat keras.
