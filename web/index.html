Pertanyaan yang Sering Diajukan

Pelajari cara kerja pembelian, aktivasi lisensi, dan dukungan perangkat keras.

Apakah benar-benar tanpa biaya bulanan atau tahunan? +
Ya, benar 100%! Anda hanya membayar satu kali saat pembelian melalui website ini. Tidak ada tagihan bulanan, tidak ada biaya langganan, dan tidak ada biaya tersembunyi. Lisensi berlaku permanen seumur hidup.
Bagaimana cara saya menerima aplikasi dan kunci lisensi setelah bayar? +
Proses berjalan 100% otomatis! Begitu Anda menyelesaikan pembayaran (scan QRIS atau transfer), sistem website detik itu juga langsung menampilkan Kunci Lisensi Resmi (Serial Key) Anda di layar beserta tombol unduh langsung file installer Windows (.exe) dan Android (.apk).
Apakah bisa dijalankan tanpa koneksi internet sama sekali? +
Bisa! BukuKasir UMKM dirancang 100% offline-first. Aplikasi tidak memerlukan koneksi internet untuk memindai barcode, melayani transaksi nota, atau mencetak struk thermal.
Printer thermal apa saja yang didukung? +
Mendukung semua printer thermal kasir standar ukuran kertas 58mm dan 80mm di pasaran, baik yang menggunakan koneksi USB kabel (di Laptop/PC Windows) maupun Bluetooth nirkabel (di HP/Tablet Android). Merk yang didukung meliputi Epson, Xprinter, Panda, VSC, Iware, Mini POS, dan lainnya.
Jika komputer saya rusak atau ganti laptop baru, bagaimana dengan datanya? +
BukuKasir UMKM memiliki fitur Cadangkan Data (Backup JSON 1 klik). Anda cukup menyimpan file cadangan tersebut di flashdisk atau Google Drive. Jika berganti laptop, cukup pasang aplikasi di laptop baru dan pulihkan datanya.
