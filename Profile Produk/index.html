Installer mandiri (NSIS) untuk komputer kasir toko. Mendukung cetak otomatis printer thermal USB (58mm/80mm) dan scanner barcode laser USB kilat.

Download Windows (.exe)
  1. Unduh berkas BukuKasir-UMKM-Setup-1.0.0.exe dari GitHub Releases di atas.
  2. Klik ganda file installer untuk memulai proses pemasangan.
  3. Pilih lokasi folder dan centang "Buat Shortcut di Desktop".

Pertanyaan Umum Calon Pembeli

Informasi transparan mengenai cara kerja, kebutuhan perangkat, dan keamanan data toko Anda.

Apakah benar-benar tidak ada biaya bulanan atau tahunan?

Benar sekali. Pembelian BukuKasir UMKM adalah sistem beli putus (sekali bayar). Setelah membeli lisensi, aplikasi menjadi milik toko Anda seutuhnya tanpa iuran bulanan, biaya perpanjangan tahunan, maupun potongan komisi per transaksi.

Bagaimana jika toko saya tidak memiliki koneksi internet?

Aplikasi ini dirancang menggunakan standar Progressive Web App (PWA) dan local storage mandiri, sehingga dapat bekerja 100% offline. Semua input kasir, pencarian barang, scan barcode, dan cetak struk tetap berjalan normal walau internet mati total.

Perangkat apa saja yang bisa digunakan untuk menjalankan sistem ini?

BukuKasir UMKM sangat ringan dan dapat dijalankan di komputer PC / Laptop (Windows 10/11, macOS, Linux) melalui browser Chrome/Edge atau aplikasi mandiri Electron. Anda juga dapat menjalankannya di tablet Android maupun iPad.

Bagaimana jika laptop saya rusak? Apakah data penjualan hilang?

Tidak akan hilang jika Anda rutin memanfaatkan fitur Cadangkan Data (Backup) dengan 1 klik. Data akan tersimpan dalam berkas JSON yang bisa Anda simpan di flashdisk atau Google Drive. Jika berpindah perangkat, cukup klik Pulihkan Data dan seluruh katalog produk serta riwayat transaksi akan kembali utuh.

Printer kasir merk apa saja yang didukung?

Mendukung seluruh printer thermal standar kasir (ESC/POS) ukuran 58mm maupun 80mm, baik koneksi Bluetooth maupun kabel USB, seperti merk Iware, Panda, Vsc, Epson, Xprinter, Kassen, dan sejenisnya.

Bagaimana alur pemesanan dan pengiriman aplikasinya?

Klik tombol Pesan via WhatsApp di bawah. Admin kami akan mengirimkan invoice serta tautan berkas master installer & lisensi software secara instan setelah pembayaran terkonfirmasi. Untuk paket siap pakai, teknisi kami siap membantu pemasangan secara langsung melalui remote AnyDesk.
