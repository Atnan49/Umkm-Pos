BukuKasir UMKM

Buku Panduan Instalasi, Aktivasi Lisensi & Penggunaan Operasional Kasir

Versi 1.0.0 (Lifetime Offline Edition)

1. Cara Instalasi Aplikasi

A. Pada Laptop / Komputer Windows
  1. Buka file BukuKasir-UMKM-Setup-1.0.0.exe yang Anda dapatkan.
  2. Ikuti petunjuk di layar (klik Next / Lanjut hingga selesai).
  3. Ikon pintasan BukuKasir UMKM akan otomatis muncul di Desktop Windows.
B. Pada HP / Tablet Android
  1. Salin file BukuKasir-UMKM-v1.0.apk ke memori HP Anda.
  2. Buka file APK tersebut dan pilih Install / Pasang.
  3. Jika muncul peringatan keamanan, aktifkan izin "Izinkan instalasi dari sumber ini".

2. Aktivasi Lisensi Resmi (Sekali Seumur Hidup)

Saat aplikasi pertama kali dibuka, layar penguncian resmi akan tampil:

  1. Masukkan Nama Toko persis sesuai yang tertera pada Kartu/Sertifikat Lisensi resmi Anda (perhatikan huruf besar/kecil dan spasinya).
  2. Masukkan 16 digit Kunci Lisensi (Serial Key) resmi yang diawali dengan BKPOS-.
  3. Klik tombol Aktivasi Sekarang & Buka Kasir.
  4. Aplikasi langsung aktif selamanya tanpa perlu koneksi internet dan tanpa biaya bulanan lagi.

3. Memilih Edisi / Modul Usaha Sesuai Toko Anda

Masuk ke menu Toko (Pengaturan) di pojok kanan atas, lalu pilih Spesialisasi Edisi / Modul Usaha:

  • 🛒 Edisi Retail & Toko Sembako: Dioptimalkan untuk kecepatan scanner barcode laser, pencarian cepat, stok barang fisik, dan pencetakan label stiker rak.
  • ☕ Edisi Kafe & Rumah Makan (F&B): Mengaktifkan tombol tipe pesanan (Makan di Tempat / Bungkus), input Nomor Meja, Catatan Khusus Menu (cth: es sedikit, tanpa sambal), dan cetak tiket dapur.
  • 🖨️ Edisi Percetakan, Fotokopi & Jasa: Mengaktifkan tombol input pesanan jasa kilat custom dan opsi pembayaran Uang Muka (DP) serta perhitungan sisa pelunasan.
  • ⭐ Edisi Multi-Usaha (Ultimate): Mengaktifkan seluruh modul sekaligus (cocok untuk toko yang memiliki kafe dan jasa cetak).

4. Menghubungkan Printer Struk Thermal (58mm / 80mm)

Setting Printer di Windows (Laptop/PC)
  1. Hubungkan kabel USB printer thermal Anda ke komputer dan nyalakan printer.
  2. Pastikan driver printer sudah terpasang di Windows (cth: POS-58, Xprinter, Epson, Panda).
  3. Di BukuKasir UMKM, klik menu Toko -> Pengaturan.
  4. Pilih nama printer Anda pada kolom "Printer Struk Thermal Terhubung".
  5. Centang "Cetak Langsung Tanpa Dialog (Silent Print)" agar struk otomatis keluar saat bayar.
  6. Klik tombol Uji Coba Cetak Struk (Test Print) untuk memastikan kertas mencetak.
Setting Printer di HP Android (Bluetooth / USB)
  1. Nyalakan printer Bluetooth Anda dan lakukan Pairing di menu Bluetooth HP.
  2. BukuKasir UMKM terintegrasi dengan dialog cetak sistem Android serta driver cetak standar seperti RawBT Print Service (dapat diunduh gratis di Play Store).
  3. Anda juga dapat langsung membagikan struk transaksi digital pelanggan rapi via WhatsApp.

5. Menggunakan Scanner Barcode Laser

Kelebihan Fitur Laser: Anda tidak perlu mengklik kolom pencarian! Kapan saja laser ditembakkan ke barcode kemasan barang, sistem langsung otomatis memasukkan barang ke nota belanja dan membunyikan nada beep konfirmasi.

6. Mencetak Label Barcode Rak Barang (Code 128)

  1. Buka menu Stok & Barcode Rak.
  2. Klik baris barang yang ingin dicetak label raknya.
  3. Pratinjau label rak (berisi Nama Toko, Nama Barang, Harga Jual, dan Barcode) akan tampil di bawah.
  4. Klik tombol Cetak Label Rak Ini untuk mencetak ke printer thermal/stiker, lalu tempelkan di etalase atau rak toko.

7. Cadangan Data (Backup & Restore)

PENTING: Karena data tersimpan aman secara offline di perangkat Anda, lakukan pencadangan data rutin setiap minggu dengan mengklik tombol Cadangkan di menu atas. File .json hasil cadangan dapat disimpan di flashdisk atau Google Drive untuk keamanan.
